# ⚡ Binary Learning Hub
Learn binary numbers, ASCII, and digital logic — fully interactive.
**No database required — pure PHP, HTML, CSS, JavaScript!**

## Features
- 📖 Lesson: Binary basics + ASCII explained
- 🧮 Binary Calculator: add/subtract/multiply
- 🔄 Converters: Text↔Binary, Decimal↔Binary
- 🎮 Games: Practice & track scores
- 🔐 Student accounts with Game Names

## Quick Start
1. Clone or download
2. Run with PHP: `php -S localhost:8000`
3. Visit `localhost:8000`
4. Register an account — done!

Data saves automatically in `data/` folder.
